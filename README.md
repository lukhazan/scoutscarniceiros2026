# Gol Stats Tracker

Tenho um time de futebol amador e controlamos as estatísticas de gols e assistências pelo bloco de notas. Gostaria de um sistema ou app que contabilizasse  automaticamente as estatísticas, com um campo para colocar os gols e assistências do jogo mais recente e ele já atualizar na tabela principal
